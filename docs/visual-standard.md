# HLPB 封面與插圖規範

使用者核准的文章封面風格為唯一依據。所有文章封面、新手區圖像與器材插圖應保持同一套插畫語言。

- 米白背景、深藍粗描邊、青綠與黃色點綴，帶適度陰影與細節的編輯插畫。
- 文章封面固定：左側分類膠囊與方正繁體深藍標題，右側主題插畫，右上 HLPB Logo。
- 封面僅分類與標題，不放摘要。全站封面比例 1672:941，完整顯示不拉伸。
- 不用簡筆線稿、火柴人、英文尺寸資訊圖或其他版型代替核准插畫。
- 技術尺寸圖放文章內文，按官方資料精確繪製，不取代插畫封面。
- 球拍拍面、拍頸與握柄軸線一致、形狀完整；文字無缺筆與變形。
- 優先重用已核准圖像。新製作封面需先給使用者看，再上站。
