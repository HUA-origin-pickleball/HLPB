這一球怎麼算？規則小測驗

五題基本規則，答完就能看解釋。答錯也沒關係，再讀一次就好。

已完成 0／5 題

1｜一般對打時，球碰到邊線算界內嗎？

一般對打碰線算界內；發球碰到非截擊區線則是例外，算短球。

看完整規則 →
2｜接發球回來，發球方能立刻截擊嗎？

接發方與發球方都要先讓球在自己這側落地一次，之後才能截擊。

看完整規則 →
3｜進入廚房區打已落地的球，可以嗎？

非截擊區限制的是截擊，並不是禁止進入；可以進區回擊落地球。

看完整規則 →
4｜截擊後因慣性踩到廚房區線，算犯規嗎？

截擊動作的慣性讓人碰到非截擊區或其界線，仍是犯規。

看完整規則 →
5｜傳統換發球計分中，接發方贏得這一球就得分嗎？

傳統換發球計分只有發球方能得分。落地得分制不同，開打前要確認採用哪一種。

匹克球規則速查

先照一場球的順序看，再點開遇到的問題。

  1. 01發球
  2. 02各落地一次
  3. 03對打與廚房區
  4. 04計分換邊
01｜發球站哪裡、打去哪？

站在底線後，將球發往斜對角的正確發球區。發球碰到非截擊區線，算短球。

看發球站位與落點 →
02｜一定要空中發球嗎？

不用。落地發球也是允許的方式：放開球，等它自然落地，再從底線後擊出。

看落地發球規則 →
03｜什麼是雙彈規則？

接發方先等發球落地；接發球回來，發球方也要等球落地。兩邊各落地一次後，才能截擊。

看雙彈規則 →
04｜廚房區能不能進？

可以進去打落地球；人在非截擊區或擊球後因慣性進區時，不能截擊。

看非截擊區規則 →
05｜壓線算界內嗎？

一般球碰線算界內。例外是發球碰到非截擊區線，屬於短球。

看壓線判定 →
06｜雙打的 0–0–2 怎麼看？

傳統雙打喊三個數字：發球方分數、接發方分數、第幾位發球員。開局的 0–0–2 有特別安排。

看雙打計分 →
07｜單打發球站哪一側？

看自己目前的分數：偶數從右側發球，奇數從左側發球。

看單打站位 →
08｜哪些狀況會犯規？

例如發球沒有進入正確區域、球落地兩次才回擊、球出界，或在非截擊區內截擊。遇到爭議先停下來釐清。

新手常見問題

沒有球拍可以參加嗎？

先問活動主辦或同行球友能不能借拍，別假設每個場地都有器材可借。

一個人去，也找得到球友嗎？

可以先看揪打球入口與活動資訊；是否能加入、程度與費用都要依開團者說明。

看到學校球場，可以直接進去打嗎？

不行。明恥與太昌國小沒有對外自由開放，先洽校方或已租借團體。

第一次上場要注意什麼？

先確認排場與輪替方式。球飛到別場時先出聲提醒，等安全再撿球；下雨或地面濕滑時先停打。

我的程度適合哪種球局？

2.5、3.0、3.5 是找球友時常見的程度參考。先看自己能否穩定發球、對打與配合，再挑適合的球局；不確定就直接告訴開團者你的經驗。
